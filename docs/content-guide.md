# 当前创作规则

用户明确指出前两轮“找小步骤、找人帮助、先歇会儿”的模式越来越偏离目标。本轮回到互动段子本身。下面规则优先于旧轮次的内容审阅。

1. 页面就是喜剧表演，不先把用户分到“求助／听故事”，不以心理引导开场。
2. 人生篇以用户最新全文为准：健康／生病、康复／死亡、天堂／地狱三个二分层。不得再加恶化中间层。
3. 好结果立即收尾，更坏结果继续递进；“只有两件事需要操心”重复产生节奏，终点突然转成老朋友聚会。
4. 保留相反答案汇合的经典问答；由用户换答案发现，界面不要提前剧透。
5. 包袱之后不追加励志总结。保持奶龙一本正经的形象，动作服务于问答停顿与反转。
6. 题材标签和整体剧场文案说明这是喜剧，不把夸张台词包装成真实问题的解决方案。

剧本接口保持 question/ending 两种节点；每个 question 恰好两个选项，ending 可有有限 rebuttal。可选 `reaction: 'bounce'` 指定结尾弹跳，其余结尾点头。内容入口列表位于 `dist/lib/conversations.mjs`。

运行 `npm test` 与 `npm run check`，再验证浏览器的入口、返回、改答、切换、动画开关和窄屏。技术检查不证明好笑。
